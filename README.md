# Notex — hazır sayt

`index.html` hazır Notex saytıdır. Quraşdırma, npm və build lazım deyil.

Bu qovluğun **içindəkiləri** GitHub repository-nin kökünə yüklə. ZIP faylını olduğu kimi yükləmək sayt yaratmır.

GitHub-da bir dəfə **Settings → Pages → Source: GitHub Actions** seç. Daxil edilmiş workflow saytı yayımlayır. Alternativ olaraq **Deploy from a branch → main → /(root)** seçmək olar.

Sayt ünvanı uğurlu yayımdan sonra Pages bölməsində görünür. Öz domenini həmin bölmədə bağlamaq olar; domenin DNS qeydləri ayrıca uyğunlaşdırılmalıdır.

Məlumatlar bu brauzerdə saxlanır; hesab və cihazlararası sinxronizasiya yoxdur. Yerli Notex.html məlumatlarını əvvəl Tənzimləmələrdən ixrac et, yeni ünvanda bərpa et. Şəxsi qeydlər bu paketə daxil deyil.
